# 基于 Edge 浏览器会话复用与多源时钟校准的校园场馆智能预约系统

深大羽毛球场预约辅助工具。放场那一秒，帮你在别人点进页面之前把场地锁进「待支付」。

付款还是自己来。程序不碰支付，也不会替你输密码。

## 装

Windows 10 / 11，有 Edge 就行。**不用自己装 Python。**

第一次双击 `启动.bat`，它会自己检测环境：缺 Python 就自动下载安装（装到你的用户目录，不需要管理员权限），然后建虚拟环境、装依赖，全程 1~3 分钟，只做这一次。

装完之后每次双击都是秒开。

> 之前下载过旧版本的：先点窗口右上角「退出」把旧程序关掉，再把新文件覆盖到原来的文件夹里。
> `capture/` 和 `.profiles/` 别删，登录状态会沿用，不用重新登。

> 网络不通导致自动安装失败的话，也可以手动装 Python 3.10 以上（python.org，安装时勾选 `Add python.exe to PATH`），再双击一次即可。
>
> 程序直接调用你电脑上的 Edge，**不需要**再执行 `playwright install`。

## 用

双击 `启动.bat`，弹出一个小窗口。

1. 第一次用，点右上角**「重新登录」**，登一次就行，之后 14 天免登录
2. 选校区 → 项目 → 场馆 → 日期 → 时段
3. 左边「场地优先级」里用 ▲▼ 排顺序，排前面的先抢
4. 点**「立即抢单」**，剩下交给程序。它会自己对时、等到整点、准点出手，你电脑时间准不准都不影响

想一次抢几个时段，就选好时段点「加入清单」，加几条都行，最后一起抢。

## 放场时间

某一天的场地是**前一天 12:30** 放出来的。

想抢 10 月 30 日的场，就得在 10 月 29 日 12:30 出手。界面上的倒计时算的是「距离下次放场」，不是距离你选的那个日期——所以它平时也有数，不是 00:00:00。

已经放出来的日期，点开始就立刻提交，不用等整点。

## 两个容易搞混的

**演练模式**（默认勾着）：只查不下单。会真的去问服务器「这个时段开了没、还剩几片」，但一个下单请求都不发。测流程用。

**同时发起 / 逐个发起**：清单里有多条时才起作用。同时发起是同一瞬间全发出去，抢到的概率最大；逐个发起更稳，但排在后面的会晚一点。

## 抢到之后

45 分钟内自己付款，超时会被释放。

## 碰到这些提示

- **该时段的预约已满** — 被人抢光了，换时段
- **该时段尚未开始预约** — 还没到放场时间，等到前一天 12:30
- **操作过于频繁** — 请求太密被限流了，把「最多连续尝试」调小，缓一会儿
- **登录态已失效** — cookie 过期了，重新登录

## 关于登录凭证

`capture/` 和 `.profiles/` 存的是你本机的登录数据，已经写进 `.gitignore`，不会跟着仓库走。

拿到这份代码的人需要自己登录一次才能用，仓库里没有任何人的账号。
